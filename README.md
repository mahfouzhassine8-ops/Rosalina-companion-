# Atlas Unified English — isolated APK build branch
Dance Atlas 3D (46 original motion studies), English Pose Atlas (288 groups), English Costume Atlas (1,407 outfits) in one Android app.
This branch exists solely for building a standard Android APK through GitHub Actions; unrelated project main branches are unchanged.
Source-hosted images require an internet connection. Individual authorized images save to Pictures/Atlas English using Android MediaStore.
For privacy, the user's personal video is NOT uploaded to this public repository. The dance gallery allows selecting that clip from the phone for comparison.
