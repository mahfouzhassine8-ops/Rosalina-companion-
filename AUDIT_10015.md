# Rosalina 10015 — Samsung Speech Crash Bypass C3

Base: fully green 10014 commit `660a1876d54be48a5aa0d1b93ea6874fa31b8437`.

Real-device 10014 diagnostics proved:
- Qwen Chat worked and was warm.
- Whisper Live transcription worked quickly.
- Android thermal status was Light during the reproduced failure.
- Output route resolved to the phone speaker.
- `com.rosalina.unified:speech` repeatedly exited with Android crash records and native tombstones while spoken output was attempted.

## Repair

- Preserve Qwen, Whisper, Chat routing, Live routing, adaptive phone capability, package identity, models and permanent signing lineage.
- On Samsung devices running Android API 36+, use Android system TextToSpeech on the normal media stream for spoken Chat and Live output instead of invoking the crashing Kokoro native path.
- If Kokoro crashes on another device, persist a compatibility fallback flag and switch future speech to system TTS.
- Classic Voice transcription now uses the dedicated `:listen` Whisper process rather than the mixed `:speech` process.
- Stop/interruption stops both native speech and platform speech.
- Kokoro files remain installed/preserved and may remain available on unaffected devices.
- No photo/video work is re-enabled.

## Acceptance

CI may prove compilation, tests, packaging and update continuity. It cannot prove audible Samsung output.
Real-device acceptance requires:
1. Text Chat can speak an answer audibly.
2. Live hears the user and speaks an answer audibly.
3. Repeated Live turns do not create new `:speech` native crash records on the Samsung compatibility path.
4. Stop/interruption stops system TTS cleanly.
5. Chat and Live remain responsive without render thermal Safe Stops.

Do not lock 10015 until those device checks pass.
