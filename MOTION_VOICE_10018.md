# Rosalina 10018 movement and voice candidate

The Live view now eases expression and head changes and settles conversational arms on interruption. Speech mouth frames close immediately on silence/stop; a new utterance cannot inherit the previous articulation. Gestures use playback onset and a 4.5-second cooldown across clauses. The view resets interpolation on lifecycle restart; animation-off and thermal reductions discard residual motion. Independent blink timing is retained.

The selected performance pace now reaches Chatterbox and optional online PCM playback. Android AudioTrack time stretching preserves pitch at 1.0 while playback-head observations keep articulation aligned with source frames. Unsupported time stretching fails before speech playback and follows the existing cancellation/fallback policy. Pace is bounded to 0.8–1.2; non-finite input uses 1.0. Diagnostics include applied playback speed and paced audio duration.

Voice options remain Android compatibility TTS, the imported Chatterbox Turbo Q4 candidate, and explicitly configured online speech. Native Chatterbox sigh/chuckle/laugh tags and provider-dependent online delivery tags are retained. No Animates voice, model weights or artwork was imported. Chatterbox controlled whisper and emotional quality are unverified; slowing or lowering volume is not claimed as a whisper. Existing phone audition/acceptance remains required before promoting the candidate.

This implements the deterministic motion/transition stage. Accurate phoneme visemes, separate pupil gaze, richer full-body artwork, a 3D rig and learned motion inference require assets/interfaces not recovered from the package and remain future work. The approved Rosalina artwork and protected voice/native baseline are retained.

Validation: 37 targeted JVM tests pass, including six new transition tests and one new pace test. Android-facing renderer/view/playback files were also compiled against an Android 15 API implementation with minimal compile-only TaskState/hex support; this is not a full application build or device test. The checksum inventory now verifies 49 source files and 52 protected baseline files. Full ARM64 build and emulator tests are configured by the candidate workflow; results must be reviewed before installation. Physical-phone lip timing, audio quality, unsupported-rate behavior, appearance and sustained thermal stability are not yet accepted.

Natural realism is now the default audition style. Select Natural, Warm, Soft anime-inspired, Bright/playful, Grounded, Soft/gentle, or Intimate/quiet. These are restrained pace/volume delivery presets with unchanged pitch, not separate trained voices, breath synthesis, or guaranteed timbre changes. Auditioning a style does not save it for replies; use the explicit save-style control after comparing. Engine promotion remains separate.
